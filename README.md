# 📄 IMG → PDF Converter (Local Web Tool)

A fast, privacy-focused **Image to PDF converter** that runs entirely in your browser.
No uploads. No server. 100% local processing.

---

## 🚀 Live Demo

👉 https://bharatyadav05.github.io/bytekimg2pdf/

---

## ✨ Features

* 📂 **Drag & Drop Upload**

  * Easily add multiple images
  * Supports quick browsing

* 🔄 **Reorder Images**

  * Drag images to rearrange PDF order

* ⚙️ **Custom Settings**

  * Page size selection
  * Image quality control
  * Layout adjustments

* 📊 **Progress Indicator**

  * Real-time conversion feedback

* 🔐 **100% Privacy**

  * All processing happens locally
  * No data is uploaded to any server

* 🎯 **Modern UI**

  * Clean, responsive, and animated interface

## ⚡ How It Works

1. User uploads images (drag & drop or browse)
2. Images are previewed in a grid
3. User can:

   * Reorder images
   * Adjust settings
4. Click **Convert to PDF**
5. PDF is generated using `jsPDF`
6. File is downloaded instantly
