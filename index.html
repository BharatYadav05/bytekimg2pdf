Features
🔒 Privacy First

All conversion runs in your browser via JavaScript. Zero bytes leave your device — no server, no cloud, no tracking.

⚡ Instant Speed

No upload wait. Processes directly in memory using the Web Canvas API & jsPDF — even large batches finish in seconds.

🔃 Custom Order

Drag image thumbnails to rearrange the page order before generating your PDF. Each card shows its page number live.

Supports A4, A3, and A5 formats. Choose auto orientation per-image or lock to portrait / landscape. Add margins from 0–20mm.

Once this page is loaded, save it to your disk and open it any time — no internet connection required to convert images.
